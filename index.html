    About WeatherVerse ☁️

    WeatherVerse is a front-end weather dashboard built with HTML, CSS, and JavaScript. It uses the OpenWeatherMap API for current conditions and a 5-day / 3-hour forecast. Explore hourly breakdowns by expanding any day on the forecast page.

    Features include saved recent cities, Celsius / Fahrenheit display, season hints from your device date, and themes that shift with the latest weather condition you viewed.
